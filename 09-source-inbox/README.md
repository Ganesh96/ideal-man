# Source Inbox

Use this page to submit or track source material for processing under `00-control/source-intake-protocol.md`.

## Add a source

Paste a URL, attach text/PDF/image files, or use this record:

```md
## <short title or source ID>
- URL / filename:
- Author and date (if known):
- Format: link | text | PDF | screenshot | image
- Why I saved it / interview relevance:
- Likely track (optional):
- Status: captured
```

Do not spend time pre-summarizing it. Processing should extract links and image content, separate claims from verification and inference, connect concepts, and create practice prompts.

## Suggested batches

- Put related items from the same topic or interview track together.
- Include the source URL alongside screenshots when available.
- If a screenshot contains several slides, preserve their order.
- State the target role or upcoming interview date only when it changes prioritization.

## Processing status

`captured → extracted → verified → expanded → practiced → retest`

Use `skip` with a short reason for duplicates, irrelevant items, or material that adds no useful concept.
