# Company Overlay: Transferable Preparation and Official References

## First principle

Company names do not define a universal interview loop. Role, level, team, location and hiring needs change the format and bar. Confirm the format with the recruiter and use the exact job description. Candidate posts are useful as practice prompts, not hiring policy.

The supplied target list is Google, Netflix, Amazon, Tesla, Microsoft, Palo Alto Networks, GEICO and Walmart. Build the core skills in the [SE II program](../01-syllabus/software-engineer-ii-interview-training-program.md), then map verified role signals to the overlay.

## Official references checked 2026-09-23

- **Google Careers:** [Resources](https://www.google.com/about/careers/applications/buildyourfuture/resources/). General resource hub, not an experienced-SWE interview specification.
- **Amazon SDE II:** [Official prep](https://www.amazon.jobs/content/en/how-we-hire/sde-ii-interview-prep). Amazon describes its role-specific coding and behavioral preparation, including robust tested code and evidence from past work. Recheck the page near the interview.
- **Microsoft:** [Technical interviews](https://careers.microsoft.com/v2/global/en/hiring-tips/technical-interviewing) and [general interview tips](https://careers.microsoft.com/v2/global/en/hiring-tips/interview-tips.html). Microsoft states interview objectives vary by role and its technical guidance discusses problem solving, design, coding and role-related experience.
- **Netflix:** [New Grad interviews](https://jobs.netflix.com/careers/new-grads). This is specifically new-grad guidance; it says interviews are role-customized and recommends discussing projects and technical fundamentals. Do not generalize the new-grad process to experienced SWE II candidates.
- **Palo Alto Networks:** [Recruiter advice](https://jobs.paloaltonetworks.com/en/senior-recruiter-palo-alto-networks-UK-tips) discusses competency-based STAR examples, not a software engineering loop specification.

No current official experienced-SWE interview specification for Tesla, GEICO or Walmart was verified for this syllabus update. Avoid filling that gap with viral “exact round” claims. Use current careers information, job description and recruiter confirmation. Previously supplied company-guide shortlinks remain preserved in the source inbox; this note does not claim their redirects are verified.

## Tailor these dimensions

- Product/domain examples should resemble the actual team’s users and constraints.
- Code in the language you can write, test and debug fluently unless the process specifies otherwise.
- Explain project work accurately, including individual scope and limits.
- Map Amazon stories to its Leadership Principles when relevant; elsewhere use published values only when relevant.
- If a role emphasizes security, data, reliability or client systems, increase practice there without dropping core coding.
